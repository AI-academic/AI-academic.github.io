Anthropic and the Howard Hughes Medical Institute's Janelia Research Campus have released the Model Hardware Standard (MHS), a software framework that lets laboratory instruments from different manufacturers communicate and be run by an AI agent coordinating an experiment. It sits between the lab computer and its instruments, so devices no longer need custom code to work together, whatever their vendor or programming language. A Carnegie Mellon computational biologist told Nature that getting from a project idea to a working experiment can easily take months; his team set one up with MHS in hours. Existing lab-automation standards such as SiLA already give instruments a common language, but were not built for AI agents.
